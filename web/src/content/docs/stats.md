统计页把每一次模型调用的 Token 与成本，按多个维度整理，方便看清"Token 花在哪"。

## 仪表盘总览

进入工作台后首页即总览：顶部是今日/近 7 日/近 30 日/累计的 Token、成本、请求数等关键指标，下方是趋势与明细。

## 按时间查看

- 切换时间范围：今日 / 近 7 日 / 近 30 日 / 累计
- 查看用量随时间的变化趋势，定位异常时段

## 按供应商查看

- 供应商 = 提供大模型的平台（Claude / DeepSeek / OpenAI / 智谱 …）
- 各供应商消耗多少 Token 与成本，找出最"烧钱"的平台

## 按 Agent 查看

- Agent = 你使用的客户端软件（Claude Code / Cursor / CC Switch / Trae …）
- 每个工具消耗多少 Token 与成本，定位哪台工具的消耗

## 按模型对比

- 各模型的 Token 消耗与成本占比
- 找出最"烧钱"的模型，按需切换更经济的档位

## 成本核算

- 内置 72 个模型参考价，支持人民币（CNY）与美元（USD）一键切换
- 汇率每日从欧央行基准更新，离线回退上次成功值 / 内置参考值

## 为什么数据是空的

刚接入代理、还没有任何请求经过时，统计页为空属正常。请依次检查：

1. 环境变量是否正确指向代理地址
2. 请求是否真的走了代理（`BASE_URL` 是否生效）
3. 时间范围是否覆盖了请求发生的时间

> 排障时建议先用一条真实请求验证，再看仪表盘是否出现数据。
