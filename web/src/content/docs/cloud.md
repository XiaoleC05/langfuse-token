云平台是 Oxelia51 的在线版本：主要提供**已同步数据的查看与跨设备恢复**。桌面端负责日常本地记账与代理接入；登录云平台后可查看云端备份的 Token 统计，并在更换设备时恢复历史账本。

## 注册与登录

- **使用云平台需要注册登录**（数据要落云端）；但浏览文档、下载、社区不需要登录
- 注册与登录入口在[登录页](/auth/sign-in)与[注册页](/auth/sign-up)
- 账户同样用于：跨设备同步、管理员管理

## 数据怎么到云端

桌面端登录账户后，可把本地账本（Token 统计，不含 API Key 与请求内容）上传 / 下载到云端；新设备登录后可下载恢复。已同步的账本在云平台「/app 设置 → 同步账本」查看。详见[桌面应用](/docs/desktop)。

## 按供应商与 Agent 查看

云平台个人工作台与桌面端口径一致：

- **供应商消耗**：按提供大模型的平台（Claude / DeepSeek / OpenAI / 智谱 …）聚合
- **Agent 消耗**：按你使用的客户端软件（Claude Code / Cursor / CC Switch / Trae …）聚合

## 支持的模型与供应商

当前支持通过代理接入的主流模型，包括：

- **Anthropic**：Claude 系列
- **OpenAI**：GPT 系列
- **国内模型**：DeepSeek、Moonshot（Kimi）、智谱 GLM 等

成本按已配置的模型定价自动换算；未配置定价的模型成本按 0 计，不虚构。
