## Oxelia51 是什么

Oxelia51 是一个**本地优先的个人 Token 记账本**：只需要改一行环境变量，让模型工具（Claude Code、Cursor、ChatGPT 等）的 API 请求经过一个代理，自动记录每一次调用的 Token、成本与异常，然后在仪表盘上多维度查看。

- **零侵入**：不装 SDK、不改代码，只改环境变量
- **多维统计**：按时间、模型、项目、会话拆解用量与成本
- **本地优先**：桌面应用数据全部保存在本地，账户仅用于跨设备同步（已支持）
- **开源**：MIT 许可证，代码全开源

## 云平台 5 分钟上手

云平台已可用，5 分钟即可跑通：

1. **注册并登录** → [注册](/auth/sign-up)，登录仅在使用云平台时必需
2. **创建项目**，获得项目的代理地址
3. **配置代理**：把模型工具的 API 地址改成代理地址，见[云平台使用](/docs/cloud)
4. **打开仪表盘**，查看 Token 与成本统计

## 桌面应用（已发布 v0.1.0）

桌面应用已发布，支持 Windows / macOS / Linux 三平台，全功能本地使用、无需登录。详见[桌面应用](/docs/desktop)。

## 核心概念

- **项目**：一次要统计的集合，可自定义名称，并支持引用一个本地文件夹（Cursor 式，🚧 开发中）
- **会话**：一次连续的对话或任务，项目下按会话归因每一笔 Token
- **代理**：介于模型工具与真实 API 之间的转发层，负责自动落账；密钥只转发、不落库
