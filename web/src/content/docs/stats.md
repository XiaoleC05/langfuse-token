统计页把每一次模型调用的 Token 与成本，按多个维度整理，方便看清"Token 花在哪"。

## 仪表盘总览

进入项目后首页即总览：顶部是今日/本段时间的 Token、成本、请求数等关键指标，下方是趋势与明细。

## 按时间查看

- 切换时间范围：近 24 小时 / 近 7 天 / 本月 / 自定义
- 查看用量随时间的变化趋势，定位异常时段

## 按模型对比

- 各模型的 Token 消耗与成本占比
- 找出最"烧钱"的模型，按需切换更经济的档位

## 按项目 / 会话查看

- 每个项目、每条会话消耗多少 Token 与成本
- 结合会话内容定位单笔大额调用

## 成本核算

- 内置 20+ 主流模型定价表，用量自动换算成本
- 支持人民币（CNY）与美元（USD）两种币种查看

## 为什么数据是空的

刚接入代理、还没有任何请求经过时，统计页为空属正常。请依次检查：

1. 环境变量是否正确指向代理地址
2. 请求是否真的走了代理（`BASE_URL` 是否生效）
3. 是否使用了正确的项目密钥
4. 时间范围是否覆盖了请求发生的时间

> 排障时建议先用一条真实请求验证，再看仪表盘是否出现数据。
