title: 设置预算告警
section: 使用

---

告警用于在 Token 消耗超出预算或出现异常时及时提醒，避免费用失控。

## 设置预算阈值

在告警设置中为项目设定预算，例如：

- 月度预算：本月累计消耗不超过某个金额
- 单次/单会话预算：单次调用或单条会话消耗的上限

当消耗达到阈值时触发提醒。

## 通知渠道

- **站内通知**：登录云平台后，在站内消息中查看
- **邮件**：绑定邮箱后，触发时发送邮件通知（需在设置中开启）

## 告警是怎么触发的

系统每 5 分钟聚合一次 Token 事件，与预算比对：

1. 聚合最近的实际消耗
2. 与设定的预算阈值比较
3. 达到阈值 → 生成站内通知，并按配置发送邮件

> 告警依赖云平台的统计管道；桌面应用提供本地预算告警（本地阈值 + 系统通知）。
